# 技術スタック (Tech Stack)

本プロジェクト（Miiiwa Portfolio）で使用されている主要な技術・ライブラリの一覧です。

## コア・フレームワーク
- **Next.js** (App Router) - フルスタックReactフレームワーク。本プロジェクトの基盤。
- **React** - ユーザーインターフェース構築ライブラリ。
- **TypeScript** - 静的型付け言語。安全で堅牢なコードベースの維持に使用。

## 3D表現・Web GL
- **Three.js** - ブラウザ上で3Dグラフィックスを描画するためのコアライブラリ。
- **@react-three/fiber** (R3F) - Three.jsをReactのコンポーネントとして宣言的に記述するためのラッパー。
- **@react-three/drei** - R3F用の便利なヘルパーライブラリ（カメラコントロール、環境マップ、パーティクル、テキスト描画など）。

## スタイリング・アニメーション
- **Tailwind CSS** (v4) - ユーティリティファーストのCSSフレームワーク。直感的なスタイリングに使用。
- **Framer Motion** - React向けの高機能アニメーションライブラリ。要素のフェードインや画面遷移の滑らかなアニメーションに使用。
- **Lucide React** - シンプルでカスタマイズ性の高いSVGアイコンライブラリ。

## 主な特徴的な実装（アーキテクチャ）
- **プロシージャル・ボクセル生成**: 外部のGLBモデルに依存せず、`InstancedMesh` と数式を用いて数千のブロックからなる地形（アイランド）をパフォーマンスを維持したまま動的に生成。
- **ハイブリッド・レイアウト**: `<Canvas>` を背面（`z-index: -1`）に固定配置し、その上に通常のHTML/CSSで構成されたコンテンツをスクロールオーバーレイさせることで、3Dの没入感とWebサイトとしての情報伝達性を両立。
- **ダイナミックカメラ制御**: `CameraControls` を用いて、オブジェクトクリック時に特定の座標へカメラがスムーズにズームイン・ズームアウトするインタラクションを実装。
