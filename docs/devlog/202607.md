# 開発ログ (2026年7月)

## 2026-07-18
### 3Dジオラマポートフォリオへのアーキテクチャ刷新
- **デザイン方針の大幅な転換**
  - 参考サイト(`haru-ni.net`)をベースに、ポートフォリオ全体を「カメラが周回するボクセル空間」にリデザインする方針を決定。
  - 初期の実装をクリーンにリセットし、新たな `feature/3d-redesign` ブランチにて開発を開始。

- **プロシージャル・ボクセルジェネレーターの実装**
  - 外部のGLBモデルに依存せず、コードと数式（サイン波・距離計算）のみで浮遊島（アイランド）を生成するアルゴリズムを構築。
  - Three.js の `InstancedMesh` を活用し、数千個のブロックを描画しつつも 60fps を保つ高パフォーマンスな描画を実現。草・土・岩の深さに応じた色分けを適用。

- **インタラクションとカメラ制御の高度化**
  - `OrbitControls` から `@react-three/drei` の `CameraControls` へ移行。
  - 光るモノリス（各セクションのアクセスポイント）をクリックした際、カメラが対象へスムーズにズームイン（Swoop in）するダイナミックな演出を追加。
  - 画面下部に「HOME」ボタンを実装し、元の全体ビューへ戻るアニメーションを構築。

- **ハイブリッド・スクロールレイアウトの確立**
  - `<Canvas>` をページの背景（`position: fixed`, `z-index: -1`）に固定。
  - トップに `100vh` の透過スペーサーを配置し、そこを3D空間の操作エリアとして確保。
  - マウスホイールで下にスクロールすると、通常のHTMLセクション（About, Products, Skills等）が下からオーバーレイしてくる構造を実装。没入感とアクセシビリティを両立させた。

## 2026-07-19
### プロシージャル・ボクセルエンジンへの全面移行（外部モデル不要）
- **方針**: MagicaVoxel等の外部制作に頼らず、コードだけで `haru-ni.net` 風のパステル・ボクセルシティをどこまで再現できるかを実装。単純な `boxGeometry` の寄せ集めだった建物を、本物のボクセル解像度へ引き上げた。

- **ボクセルエンジンのコア (`src/components/3d/voxel/`)**
  - `VoxelModel.tsx`: 数千個の小キューブを **1つの `InstancedMesh` + インスタンスごとの色**で描画（1モデル1ドローコール）。60fpsを維持。
  - `builders.ts`: `fillBox` / `shellBox` / `carve` / `paint` / 簡易ノイズなど、ボクセル配列を手続き生成するヘルパー群。
  - `text.ts` / `VoxelText.tsx`: 任意の文字列をオフスクリーンCanvasでラスタライズし、**フォント→ボクセル文字**へ自動変換（"GAME"/"PRODUCTS"等の立体看板をコード生成）。
  - `palette.ts`: 世界観を統一するパステルパレットを一元管理。

- **街の構築**
  - `VoxelIsland.tsx`: 草／土／石の層と、ピンクの環状道路・十字路・中央広場を持つ**浮遊島**を数式で生成（先細りの底面）。
  - `ProceduralObjects.tsx`: 5セクションのアンカーをボクセル建築で再構築（Aboutの家、Products のピンク・ランドマークタワー、Skills の青いタワー、Experience の図書館、Contact の看板）。ホバーで浮上、クリックでカメラズーム。ラベルは `Billboard` で常時カメラを向く。
  - `Decorations.tsx`: 観覧車（回転）、木、街灯、雲、歩き回るNPC、降り注ぐパステル紙吹雪（`Confetti`）を追加。
  - `VoxelBus.tsx`: 環状道路を周回するボクセル・トラムに刷新。

- **UIオーバーレイの自分ごと化**
  - 借用していた「App Factory はる」等のコピーを全て撤去し、Miiiwa自身の情報（bio・SNS・モットー「面白いを最優先！」）へ差し替え。日英切り替え対応。
  - セクションに応じて内容が切り替わる左カード、`HOME` ボタン、隠しターミナル起動ボタンを実装（`TerminalOverlay` の描画を復帰）。

- **検証**: `next build`（静的エクスポート）成功。ヘッドレスChrome + SwiftShader で実描画をスクリーンショット確認し、ズーム／カード切替／HOMEボタン等のインタラクションが動作することを確認（コンソールエラーなし）。
